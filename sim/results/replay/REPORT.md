# 학습된 정책 리플레이 (시뮬레이터)

`models/sim_balance_v4_4M_seed2.pt`(약 4M 스텝)를 파이썬 시뮬레이터에서 실제로 돌린 기록이다.

- 뷰어: `replay.html`을 브라우저로 열면 된다(데이터가 파일 안에 들어 있다).
- 다시 만들기:

```bash
python sim/record_replay.py --checkpoint models/sim_balance_v4_4M_seed2.pt --games 100 --keep 4 \
    --out sim/results/replay/replay.json --html sim/results/replay/replay.html
```

## 읽는 법

- **사보타주는 배웠다.** 무작위일 때 부수기 1회였던 것이 17회로 늘었다. 한 방을 집중해서 부숴 '완전 파괴'로 이긴다.
- **인간팀 정책은 무작위와 구분되지 않는다.** 같은 학습 사보타주를 상대로 학습 인간팀 83%, 무작위 인간팀 85%다(100판씩, 오차 범위 안).
  - 수리·끊기·사격의 대부분은 규칙(자동 수리, 근거 사격)이 만든다.
  - 학습 중 인간·함장 엔트로피가 균등분포 근처(4.0~4.3)에 머문 것과 일치한다.
- 학습 통계와 같은 조건으로 재기 위해, 게임이 끝날 때마다 트레이너처럼 `env.reset()`을 호출한다. 리셋을 빼면 결정 타이밍과 저장된 행동이 달라져 수치가 어긋난다(부수기 약 10회, 인간 승률 약 87%).
- Unity가 아니라 Unity C# 규칙을 옮긴 시뮬레이터다(직선 이동).
