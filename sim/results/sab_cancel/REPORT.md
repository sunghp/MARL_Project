# 규칙 변경: 부수기 도중 취소·도주

진단에서 목격된 사보타주의 74%가 처형됐다(목격 후 중앙값 18.8초, `../saboteur_improve`). 부수기 3초 동안 움직일 수 없는 것이 원인 중 하나로 보였다.
그래서 부수는 도중 취소하고 도망칠 수 있게 규칙을 바꿨다.

**결론: 승률이 오르지 않았다.**
- 학습 사보타주는 취소를 거의 쓰지 않았다(판당 0.1~0.4회).
- 규칙봇에게 도주를 시키면 오히려 손해였다.
- 기본값은 끔(`sab_cancel: 0`)으로 두고, 최종 모델도 그대로 둔다.

## 규칙 (env param `sab_cancel`, 시뮬레이터와 C# `NPCAgent`·`GameManager`)

| 모드 | 내용 |
|---|---|
| 0 | 없음 (기존) |
| 1 | 부수는 중 지금 방이 아닌 방을 고르면 취소하고 그 방으로 이동. 진행분은 사라짐 |
| 2 | 부수는 중 **상호작용 2(취소 버튼)** 와 다른 방을 함께 골라야 취소. 사보타주에게 상호작용 2는 원래 쓸모없던 칸 |

- 취소 횟수: `sab_cancelled`, Unity 통계 `behavior/sabotage_cancelled`
- 규칙봇 사보타주의 도주: `bot_flee` (기본 끔). 목격당했고 함장이 사거리 + 5 안이면 취소하고, 함장에게서 먼 방으로 간다.

## 규칙만 바꿨을 때 (학습 없음, 500판, `ladder.txt`)

| 사보타주 | 기존 | 취소 규칙 |
|---|---|---|
| 규칙봇 사보타주, 도주 안 함 | 42% | 42% |
| 규칙봇 사보타주, 도주 (`bot_flee 1`) | — | 27% |
| (참고) 규칙봇, 인간팀이 보이면 즉시 취소 | — | 24% |
| 방 붙기 스크립트 | 17% | 18% |

- 시야가 서로 같아서, 인간팀이 보이는 순간 이미 목격된 상태다. 보자마자 취소하면 진행분만 날린다.
- 함장은 사보타주와 같은 속도로 근거 있는 대상을 계속 쫓아온다. 도망치는 동안 부수지 못하니 시간만 잃는다. 판당 처형은 1.31명에서 1.56명으로 오히려 늘었다.

## 학습

### 모드 1: 학습이 무너짐

기준 C 설정(사보타주 엔트로피 0.003, 학습률 3e-4)에 모드 1을 더해 시드 6개를 돌렸다(관측 v1·v2 각 3개).
- 2M 스텝에서 승률이 0~2%였고, 일부 시드는 부수기를 아예 하지 않게 됐다. 기존 규칙에서는 같은 시점에 25~35%였다.
- 원인: 학습 초반 무작위 행동은 0.4초마다 다른 방을 고를 확률이 약 78%다. 그래서 3초짜리 부수기가 거의 끝나지 않았고, 부수기 보상을 받을 기회가 사라졌다.
- 그래서 중단하고 모드 2로 바꿨다.

### 모드 2: 세 가지 비교 (시드 2개, 500판, 평가 시드 777, `runs_4M_500games_seed777.txt`)

| 실험 | 내용 | 시드 0 / 1 | 평균 | 판당 취소 |
|---|---|---|---|---|
| (출발점) | 현재 최종 모델, 모드 2에서 평가 | 41% | | 0.19 |
| G1 | 처음부터 4M + 모드 2 | 29% / 16% | 23% | 0.1~0.2 |
| (참고) C | 처음부터 4M, 규칙 그대로 | 40% / 35% | 37% | — |
| G2 | 최종 모델에서 +4M + 모드 2 | 23% / 30% | 27% | 0.3~0.4 |
| G3 | 최종 모델에서 +4M, 규칙 그대로 (대조군) | 31% / 34% | 33% | — |

학습 중 승률(마지막 1M 구간)은 다음과 같다. 출발점 모델의 학습 중 수치는 37%였다.
- G2: 37% / 37%
- G3: 34% / 35%
- G1: 29% / 20%

## 해석

1. **취소 규칙은 승률을 올리지 않았다.**
   - G2(규칙 있음)와 G3(규칙 없음)는 학습 중 수치로 약 3%p, 마지막 체크포인트 평가로는 -6%p 차이다. 시드 편차 안이다.
   - 처음부터 학습하면(G1) 오히려 느려졌다. 취소라는 선택지가 탐색을 방해한다.
2. **학습 사보타주는 취소를 거의 쓰지 않는다**(판당 0.1~0.4회). 이 게임에서 도주의 값어치가 낮다는 뜻이다.
   - 함장이 같은 속도로 끝까지 쫓아온다.
   - 부수려면 3초 동안 멈춰 있어야 한다.
   - 그래서 도망쳐도 다시 부수는 순간 따라잡힌다. 규칙봇 도주 실험(42% → 27%)과 같은 결론이다.
3. **최종 모델을 더 학습시키면(G3) 오히려 평가가 떨어졌다**(41% → 33%).
   - 41% 모델은 학습 곡선에서 좋은 지점에 걸린 체크포인트다.
   - 같은 설정으로 더 학습해도 정책은 30~40% 사이를 오르내린다.

## 남긴 것

- `sab_cancel`(0/1/2), `bot_flee`: 기본 0. yaml에도 0으로 명시했다.
- C#: `GameManager.sabCancel`(int), `NPCAgent` 취소 처리, `RecordSabotageCancelled`. 컴파일만 확인했다.
- 행동 막기(`--action-mask`)를 켜면 사보타주는 상호작용 0·1만 쓸 수 있어서 모드 2의 취소 버튼을 누를 수 없다. 같이 쓰려면 `ROLE_VALID_INTERACTIONS["saboteur"]`에 2를 더해야 한다.
